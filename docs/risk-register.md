# Risk Register — Claims Fraud-Investigation Copilot (BC-AAIE-HACK-09)

Scope: the LangGraph multi-agent copilot in this repository, running locally on synthetic data with Google Gemini
(default `gemini-3.5-flash-lite`; evidence generated on `gemini-3.5-flash`) as the only model provider. Categories use the **OWASP Top 10 for LLM Applications (2025)**
(LLM01–LLM10) and the **NIST AI RMF 1.0** functions (GOVERN / MAP / MEASURE / MANAGE).
Every mitigation cites the committed control that implements it and the committed evidence that shows it working.
`tests/test_citations_resolve.py` checks that every path cited below exists.

Scales: Likelihood / Impact / Residual = Low · Medium · High (inherent likelihood before controls).

## Review cadence
Re-assess after any change to prompts, indicator weights, model version or guardrails; re-run
`python -m scripts.regenerate_evidence` and `python -m pytest` and update residual ratings from the new evidence.
